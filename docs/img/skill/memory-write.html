MindBridge Memory Write Path

A short claim transaction assigns the lease; a second locked transaction validates and writes memory.

Transactional outbox

  • • Eligible job commits with the reply
  • • Disabled or crisis turns enqueue none
  • • Content stays in messages
  • • Only IDs and versions are queued

Processing locks

  • • User -> Conversation -> Job order
  • • Gates rechecked before extraction
  • • Locks span LLM and Store calls
  • • Completion commits atomically

Lease

  • • lease_until is the ownership token
  • • A crash lets the lease lapse
  • • Stale tokens cannot write back
  • • Episode write checks epoch + revision
